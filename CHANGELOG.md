# Changelog

All notable changes to Manetho project are documented here.

## [1.0.0] - 2026-10-07

### Added
- Complete transformation from Forge SaaS to Manetho editorial blog
- 20 historical articles with full metadata (author, sources, reading time)
- 10 pharaoh profiles with dynasties, achievements, monuments
- 8 archaeological sites with galleries and historical data
- 20+ timeline events spanning Ancient Egyptian history
- 6 editorial categories (Civilization, Pharaohs, Archaeology, Mythology, Discoveries, Artifacts)
- Full-text search functionality across all content
- Reading experience features (bookmarks, sharing, progress bar, dark mode)
- Complete SEO optimization (meta tags, Open Graph, JSON-LD schemas)
- Responsive design (360px-1920px)
- WCAG AA accessibility compliance
- GitHub CI/CD workflows
- Docker containerization
- Vercel deployment configuration

### Removed
- All Forge SaaS branding and messaging
- Pricing and subscription tiers
- Testimonials and fake statistics
- Developer platform features
- Taiga UI dependencies
- Netlify configuration

### Changed
- Reorganized project structure with features folder pattern
- Updated routing to support editorial content architecture
- Redesigned homepage as editorial publication landing page
- Updated navbar and footer with Manetho branding
- Refactored styling to editorial design system (charcoal/ivory/gold/lapis)
